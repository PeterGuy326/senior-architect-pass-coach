数据与边界 · 公开说明

学习档案留在浏览器，Agent 只拿到必要上下文

这个产品没有账号系统、服务器档案、广告脚本或行为遥测。它只有在你点击建档后， 才在当前浏览器保存复习状态；只有你显式连接 Local Agent Runtime 后，才把本轮必要信息交给所选模型服务。

保存什么

  • 考试日期和每日学习时长等本地设置；
  • 已完成的任务、作答结果、自动派生的证据等级和弱项状态；
  • 每题有界的前台有效用时、首次选择用时、改选次数和派生行为信号；不保存按键流、焦点历史或选择轨迹；
  • 会话 revision 与当前题目标识，用来防止重复提交。

原始输入文本和参考答案不作为长期学习档案保存。网页使用浏览器站点存储；换浏览器、 换设备、使用无痕模式或清理网站数据后，原档案不会自动出现。

用时只帮助识别“可能在猜、较犹豫、呈熟练倾向”等复测信号，不是对人的能力定论。 参考时间先按题干、选项和逻辑负荷估算；至少积累 6 条合格记录后，才用最多 48 条权重的 离散节奏分桶做个人校正。你无需自报把握度；快答正确、计时不完整或反复改选只会安排复测， 不会因单题被升级为掌握。慢读且没有反复改选也不会单独判成不会。页面被隐藏、失焦或刷新后，残缺计时不参与行为判断。

不会做什么

  • 基础模式不调用大模型；网页不读取、上传或保存 API Key；
  • 不接入第三方字体、统计、广告、客服或会话回放脚本；
  • 不把你的作答、错题和学习进度写入公开仓库、Issue 或 Pull Request；
  • 不根据缺失数据猜测进度——没有作答证据时，会明确说不知道。

连接本机 Agent 后

公开 Pages 始终是学习主页面。Runtime 只监听 127.0.0.1；只有你点击连接后， 浏览器才打开 Runtime 自己的确认窗口并请求本地网络访问许可。确认窗口不能读取学习档案， 只向发起连接的 Pages 窗口返回一份绑定到精确来源的短期授权。

明文 Bearer 在浏览器侧只短暂经过确认页的 JavaScript 对象，之后只留在 Pages 的 JavaScript 私有字段；Runtime 只保留其摘要与绑定 Origin。它不进入 URL、DOM、IndexedDB、 localStorage、sessionStorage、导出文件或日志；刷新页面或重启 Runtime 后需要重新确认。后续接口只接受精确的正式 Pages Origin，不使用 wildcard CORS 或 cookie。 切换 Claude、Qwen、CodeBuddy 或退回基础私教，不会更换浏览器里的档案，也不会让模型获得写进度的权限。

为生成个性化讲解，本轮公开题面、作答、可信答案解析和去标识化弱项摘要（可含“犹豫 / 可能猜测 / 熟练倾向”等派生枚举，但不含精确计时）可能会交给所选 Agent Host 及其模型服务；自然语言追问也会发送。姓名、账号、浏览器档案原文、本地路径和 API Key 不会进入员工包输入。模型服务自身如何处理请求，仍受用户配置的服务条款约束。

选择 Codex CLI 时还会要求一次单独确认。该个人实验模式只在当前 Runtime 内存授权中有效， 会让本机 Codex CLI 通过短生命周期的临时链接复用已有 ChatGPT / Codex 登录；本项目不读取、 复制或记录登录文件内容。每轮以 ephemeral 进程运行，Prompt 走标准输入，临时目录随后删除。 提交后只向 Codex 模型服务发送科目、考点、掌握结果和去身份化进度，不发送题干、选项、 用户作答、参考答案或解析；Codex 只能选择枚举化补救计划，再由本地模板显示。无题面复习时， 你主动输入的追问会发送给 Codex。上述资料按你自己的 OpenAI 账号和服务条款处理。

Digital Employee 0.3.0 对 Codex 仍只报告 probe_only。个人实验模式会关闭 模型工具网络与写入权限、禁用已知工具，并在出现任何工具事件、提交轮自由文本或无效结构化输出时拒绝本轮； 但它不冒充已经通过框架工具白名单认证。无论本轮 Codex 是否成功，固定判分和已经提交的进度都不会回滚。

桌面 Chrome/Edge 是当前 Agent 配对主路径。Safari、Firefox、受管浏览器或移动设备如果不允许 公开 HTTPS 页面访问本机 HTTP loopback，会继续使用基础私教；项目不会改为监听局域网地址来绕过限制。

题库从哪里来

综合客观题按需读取自公开仓库 PeterGuy326/senior-software-architect-review 的固定提交 88f4bdc58e668ac887f2f06e152f69a1c129edd1。 固定 revision 可以避免题目在你不知情时随远端更新变化。请求由浏览器直接发往 raw.githubusercontent.com，GitHub 仍可能按照其服务规则看到常规网络访问元数据。

导出、导入和清除

“导出档案”会在本机生成一份 JSON 文件，不会自动上传。该文件包含私人学习记录， 请像保管错题本一样保管它。“导入档案”只读取你主动选择的 JSON 文件；导入前会校验格式。 “清除本机数据”会删除这个站点在当前浏览器里的私人档案，操作前会再次确认。

当前产品边界

这是可直接使用的 MVP，目前只覆盖系统架构设计师考试的综合知识客观题。 案例分析与论文训练尚未开放。Digital Employee 在本项目中负责员工包契约与可替换 Agent Adapter； 网页的选题、判分和进度更新仍是确定性的本地流程，Agent 只补充讲解与追问回答。

作答前不显示答案是一道教学体验门，不是防破解的安全边界。设备所有者仍能使用开发者工具 查看浏览器收到的外部题库文件或修改本地 IndexedDB；如果未来需要真正的答案保密、账号认证 或防篡改进度，就必须引入并明确披露服务端。

外部复习仓库目前未声明许可证（NOASSERTION）。本项目不把题库正文打包进网页， 本项目的 Apache-2.0 许可证也不覆盖这些外部资料。
