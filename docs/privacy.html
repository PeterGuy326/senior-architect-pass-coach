数据与边界 · 公开说明

你的学习档案，只留在你的浏览器里

这个网页没有账号系统、服务器档案、广告脚本或行为遥测。它只有在你点击建档后， 才在当前浏览器保存复习状态。

保存什么

  • 考试日期和每日学习时长等本地设置；
  • 已完成的任务、作答结果、信心标记和弱项状态；
  • 会话 revision 与当前题目标识，用来防止重复提交。

原始输入文本和参考答案不作为长期学习档案保存。网页使用浏览器站点存储；换浏览器、 换设备、使用无痕模式或清理网站数据后，原档案不会自动出现。

不会做什么

  • 不调用大模型，不上传 API Key，也不要求你配置模型账号；
  • 不接入第三方字体、统计、广告、客服或会话回放脚本；
  • 不把你的作答、错题和学习进度写入公开仓库、Issue 或 Pull Request；
  • 不根据缺失数据猜测进度——没有作答证据时，会明确说不知道。

题库从哪里来

综合客观题按需读取自公开仓库 PeterGuy326/senior-software-architect-review 的固定提交 88f4bdc58e668ac887f2f06e152f69a1c129edd1。 固定 revision 可以避免题目在你不知情时随远端更新变化。请求由浏览器直接发往 raw.githubusercontent.com，GitHub 仍可能按照其服务规则看到常规网络访问元数据。

导出、导入和清除

“导出档案”会在本机生成一份 JSON 文件，不会自动上传。该文件包含私人学习记录， 请像保管错题本一样保管它。“导入档案”只读取你主动选择的 JSON 文件；导入前会校验格式。 “清除本机数据”会删除这个站点在当前浏览器里的私人档案，操作前会再次确认。

当前产品边界

这是可直接使用的 MVP，目前只覆盖系统架构设计师考试的综合知识客观题。 案例分析与论文训练尚未开放。Digital Employee 在本项目中是员工包契约和运行规范的基础设施， 不是一个隐藏的大模型聊天服务；网页的选题、判分和进度更新都是确定性的本地流程。

作答前不显示答案是一道教学体验门，不是防破解的安全边界。设备所有者仍能使用开发者工具 查看浏览器收到的外部题库文件或修改本地 IndexedDB；如果未来需要真正的答案保密、账号认证 或防篡改进度，就必须引入并明确披露服务端。

外部复习仓库目前未声明许可证（NOASSERTION）。本项目不把题库正文打包进网页， 本项目的 Apache-2.0 许可证也不覆盖这些外部资料。
