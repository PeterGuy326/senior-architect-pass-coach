数据跟着本地仓库走，不跟着这个网页走。

当前 GitHub Pages 只是静态使用说明，不建档、不出题、不判分、不连接 Local Agent Runtime， 也不读取或保存你的作答和学习进度。

当前保存在哪里

私人档案、答题记录、错题、项目素材和会话记录默认只保存在复习仓库根目录的 .study/。该目录被 Git 忽略，不能提交到公开仓库。正式模拟考试由复习仓库中的 本机服务提供，交卷记录仍写回同一目录，当前 Agent 可直接读取。

这个网页会做什么

  • 从同一 GitHub Pages Origin 加载首页样式、脚本、Manifest 和 Service Worker；
  • 把你主动点击的链接导航到公开 GitHub 仓库；
  • 用 Service Worker 缓存少量同源静态首页文件，方便刷新与离线展示。

页面没有账号、遥测、广告、第三方字体、API Key 表单或模型代理接口。GitHub 作为托管方仍可能 按其服务规则处理常规网络访问元数据，例如 IP 地址和 User-Agent。

Agent 与模型服务

你选择的 Codex、Claude Code、Qwen Code 或其他本地 Agent 是交互入口。Agent 是否调用外部模型、 发送哪些上下文以及如何处理请求，取决于你使用的 Agent、账号和本机配置；请以对应服务条款为准。 本项目要求 Agent 不把私人学习数据写入公开题库、Issue 或 Pull Request。

旧版浏览器档案

早期预览版曾把学习进度放在本 Pages Origin 的 IndexedDB，并通过 Runtime 配对 Agent。 当前首页不会读取、迁移或继续更新那份旧数据；旧配对页也已停用。若不再需要，可在浏览器的网站数据设置中 删除 peterguy326.github.io 下本项目的 IndexedDB 与缓存。
