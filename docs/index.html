01 / 开始

三步，不建另一套账号体系

仓库里的 Agent 规范、题库和进度协议共同构成老师；你原本使用的 Agent 就是交互入口。

  1. 壹

    取得复习仓库

    Clone 或在支持 GitHub 仓库的 Agent 中打开 senior-software-architect-review。

  2. 贰

    直接告诉 Agent 目标

    它会先检查本机私人进度；没有档案就明确建档和诊断，不会编造你的水平。

    开始私教，我只求考过。
  3. 叁

    按真实作答继续

    说“今天学什么”“复习错题”或“启动综合模拟考试”，Agent 会读取同一份本地证据接着教。

02 / 机考

网页只做它擅长的事：考试。

75 道高频题、150 分钟倒计时、答题卡、标记、刷新恢复、交卷判分和错因反馈。 页面不聊天、不代理模型；答完以后把逐题答案、用时和错因写回本机 .study/，当前 Agent 再据此因材施教。

由 Agent 自动启动，或在复习仓库根目录运行 python3 scripts/serve.py
